**Gotcha discovered during implementation**: `WorkManagerTestInitHelper.initializeTestWorkManager()` had to be added to every Robolectric test class that launches `HomeFragment` or `SettingsFragment` (4 files in `feature/home`, `SettingsFragmentTest`, `SettingsWidgetRefreshTest`) — `onResume()`/`onSave` now touch real `WorkManager` unless the sync-request seams are overridden, and Robolectric doesn't auto-initialize `WorkManager`. Also: `enqueueUniqueWork()` doesn't block for completion, so a bare `idle()` right after triggering a save is not a reliable wait for the resulting `ApiSyncWorker.doWork()` to finish — tests need to poll (`idle()` + short `Thread.sleep()` in a loop) for the expected outcome instead. Separately: invoking `FragmentScenario.onFragment {}` itself from a raw background JVM `Thread` deadlocks in Robolectric — for the regression test's genuine concurrency, the *first* (superseded) request must be triggered via a direct `ApiSyncScheduler` call on the background thread, with only the *second*, real request driven through the actual Fragment UI on the main thread.
